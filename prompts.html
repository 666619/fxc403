任务二 · creative 仿写 ⭐⭐⭐

自学第 7 种效果：creative 电影墙

参考官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法。

我的提问
我在 Swiper11 里想加第 7 种效果 creative，参考官方示例 257-effect-creative。请问 creativeEffect 里的 prev 和 next 分别控制什么？transform 里的百分号是相对谁的？给我一个"上一张缩小左移带角度、下一张放大右移进场"的配置例子。
AI 回答
prev 控制正在滑出屏幕的上一张幻灯片的变换样式；next 控制即将滑入屏幕的下一张幻灯片的变换样式。
translate 三个值依次是 X（左右）、Y（上下）、Z（前后纵深）轴位移；rotate 是绕轴旋转角度；scale 是缩放倍数。
百分号是相对于当前 slide 自身的宽度计算，-120% 即向左移动 1.2 个自身宽度。 
creativeEffect: {
  prev: { translate: ['-120%', 0, -250], rotate: [0, 0, -12], scale: 0.7 },
  next: { translate: ['120%', 0, -250], rotate: [0, 0, 12], scale: 1.15 }
}
我的追问
如果想让卡片转 20 度，应该改哪个值？
AI 回答
改 rotate 数组里对应轴的数值。比如 rotate: [0, 0, -20] 是绕 Z 轴（屏幕法线）转 20 度，rotate: [0, 20, 0] 是绕 Y 轴左右翻转 20 度。prev 与 next 角度方向要相反，才有对向翻动的选片墙效果。
我用自己的话写下（prev / next 各控制什么）
• prev：控制离开屏幕的上一张——缩小、左移、带角度退场，像电影墙里被挑走的海报；
• next：控制从右侧进场的下一张——放大、右移、带反向角度进入，形成立体错落感；
• transform 中的 % 是相对 slide 自身宽度，不是相对浏览器窗口。
一句话验证结论（✅ 通过）
点击「creative 电影墙」按钮后，上一张缩小左移带角度退场、下一张放大右移带角度进场，效果符合电影选片墙要求。

任务三 · 综合创作 + 技术答辩 ⭐⭐⭐

新增爱达·魔都号 + 自选超纲能力 keyboard

我的提问（keyboard）
给 Swiper11 轮播加一个 keyboard 键盘控制功能，用户按键盘左右方向键可以切换幻灯片，应该怎么写？顺便提醒我需要注意什么。
AI 回答
在初始化配置根级加上： 
keyboard: {
  enabled: true,
  onlyInViewport: true
}
enabled:true 开启键盘方向键控制；onlyInViewport:true 表示只有轮播处于视口可见范围才响应按键，避免页面其他区域误触。注意需要先点击轮播区域获得焦点，按键才会生效，这是浏览器焦点机制。
我做的修正
AI 最初只给了一段单独带 keyboard 的初始化代码。但本页效果切换采用"destroy + new 重建"，直接替换会导致切换效果后键盘失效。因此我把 keyboard 配置同时写进初始化和按钮重建两处，保证切换任意效果后键盘仍可用。
